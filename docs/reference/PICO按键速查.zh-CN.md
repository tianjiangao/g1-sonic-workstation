# PICO × SONIC × G1 按键速查

2026-10-27按本机代码核对。仅说明按键，不代表所有运动模式已经真机验收。本轮学习不启动机器人。

## 手柄位置

- 机器人左右始终按机器人自身判断。
- 左手柄圆键X、Y；右手柄圆键A、B。
- Trigger是食指前方扳机；Grip是手柄侧面的握持键，两者不同。
- 摇杆“推动”和“垂直按下”是两个不同输入。
- 组合键同时按一次后全部松开，再做下一步，避免重复切换。

## 常用操作

| 按键 | 作用 | 适用条件 |
|---|---|---|
| ABXY四键同时按 | OFF时开始策略、做首次标定并进入PLANNER；运行时再次按则停止并退出 | 必须先启动程序、等Init Done。不是给机器人上电；INIT本身就会带力 |
| A+X | PLANNER↔POSE切换；VR_3PT中也可切回POSE | 进入POSE前先与机器人姿态对齐。不是启动已退出程序的按键 |
| A+B | 规划模式中选择下一个运动模式 | IDLE(0)时按一次到SLOW_WALK(1)；连续按会进入Walk/Run/蹲跪/跳跃等，首次只选慢走 |
| X+Y | 规划模式中选择上一个运动模式 | Slow Walk(1)按一次回Idle(0)；不是急停 |
| 推动左摇杆 | 规划模式控制前后、横向移动 | 先确认SLOW_WALK；IDLE下即使输入正常也不执行行走。POSE中的脚步由真人腿部动作输入 |
| 右摇杆向左/右推 | 规划模式改变目标朝向 | POSE代码也包含该输入的朝向微调，本机尚未单独验收该用法 |
| 左食指扳机 | 按压逐渐闭合机器人自身左夹爪，松开张回本轮启动开度 | 左右映射已真机修正并验收；不是摇杆下压键 |
| 右食指扳机 | 同上，控制机器人自身右夹爪 | 侧面Grip不是Dex1开合键 |

## 进阶键

| 按键 | 作用 | 注意 |
|---|---|---|
| B+Y | POSE↔冻结上半身的规划模式；VR_3PT中也可返回POSE | 不是暂停或急停！下肢仍在策略控制，摇杆仍可控制移动，夹爪也仍可操作 |
| 按下左摇杆 | 从规划模式进入VR_3PT（三点跟随），重新标定头/双腕关系中的手腕偏移；再次按返回原规划模式 | 不是夹爪键。先对齐姿态；本机真机尚未完整验收三点模式 |
| 按住左菜单键 | POSE中进入POSE_PAUSE，松开回POSE | 暂停姿态流，不是电机停止。目前夹爪适配层会因模式暂停而停发，需要重新处理夹爪映射；不作为常用整机暂停键 |
| 右摇杆上下、右摇杆下压 | 当前SONIC管理器没有对应的常用运动操作 | 不要与左右推动转向、左摇杆下压混淆 |
| 单独A/B/X/Y | 当前管理器没有对应的单键身体模式操作 | XRoboToolkit的A键发送切换必须关闭，否则A会额外影响数据发送 |

## 数据采集键

| 按键 | 作用 |
|---|---|
| 左Grip+A | 开始/停止当前episode录制 |
| 左Grip+B | 录制时把episode保存为discarded并结束该条录制，不是直接删除文件 |

只有官方采集器正在运行且数据有效时，录制键才有效。当前真机完整相机＋Dex1训练episode尚未验收，不能把终端诊断日志当作已完成数据采集。

## 模式含义

- PLANNER：摇杆规划行走/转向，身体由策略控制；其中IDLE、Slow Walk等是另一层“运动模式”。
- POSE：PICO全身SMPL跟随，含双臂、髋膝踝及脚步；不是世界位置和距离的一比一复刻保证。
- PLANNER_FROZEN_UPPER_BODY：上半身保持切换时目标，下肢继续规划控制。
- VR_3PT：头＋双手三点跟随，腿仍走Planner。
- OFF：策略未启用或已请求停止；本机停止后程序会退出，恢复需重新启动。

## 最常用顺序

1. 头显XRoboToolkit前台，Full Body/Send开启，Switch w/ A Button关闭。确认夹爪处于准备好的张开状态，所有摇杆回中，扳机和Grip松开。
2. 在SONIC工作站启动真机程序，等待Init Done；INIT本身会带力。
3. 标定站姿：站直、双脚并拢、上臂贴身、肘弯90°、前臂向前、掌心相对。ABXY一次，松开等3秒。
4. 想用摇杆走：先留在PLANNER，日志若为IDLE，AB一次并松开，确认`Mode -> 1: SLOW_WALK`后轻推左摇杆；右摇杆控制目标朝向。
5. 想全身跟随：摇杆回中、身体先对齐机器人姿态，AX一次并松开，进入POSE，再做小幅动作。AX再次按返回PLANNER。
6. 想夹取：左右食指扳机控制对应夹爪，松开返回本轮启动开度。
7. 结束：先恢复平稳姿态，松开扳机让夹爪回到准备开度，再按ABXY。停止过程不是断电，落地机器人始终由现场人员看护。

## 停止区别

- ABXY：SONIC软件停止并退出，不等于独立急停或电机断电。
- C++控制器所在终端O：软件停止；不是在任意终端输入O。
- 工作站“停止本次作业”：只管理该窗口启动的会话；不能替代独立急停。
- B+Y、AX、菜单键、摘下头显、关闭Send都不能当作常规整机急停。
- 独立急停由现场旁站人员持有。真实丢包、NaN/Inf等仍可触发相应保护，不能保证只有人工按键才停止。
