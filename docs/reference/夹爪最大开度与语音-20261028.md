# 夹爪全开与语音增强（2026-10-28）

本次依据用户明确要求：工作站启动遥操与数采后，两只夹爪自动打开到最大开度；语音更响。保持锁定官方源文件、左右物理映射、DDS主题、增益和失效保护。

工作站给夹爪适配器传入 `--open-on-start`。只有 SONIC 已进入实际 CONTROL、g1_debug/左右状态/手柄输入均新鲜、两扳机松开至少250ms后，才从当前开度以0.5rad/s上升到官方5.4rad全开目标。单次循环最大按50ms计算，延迟不会造成大步跳变。用户按下某侧扳机会结束该侧自动张开，从实测开度闭合；松开回全开。未激活SONIC或只启动被动数采不会自动张开。

停止、退出活动模式或数据过期后停发，故障后的新输入不会自动重新解锁，须人工重新启动。没有扩大官方0–5.4rad目标范围，没有改变kp=5、kd=0.05、官方0.18rad单步跟随限制及原有物理左右映射。启动对话框明确告知自动张开，须留空完整夹爪行程。

原问题有两层：松开目标被截在本轮初始开度；官方WeightedMovingFilter丢弃重复采样，使目标稳定后残差不继续收敛。适配器现在按采样时间推进重复值的滤波历史，继续使用锁定官方滤波器及原权重；没有改写vendor文件或哈希锁。

高级手动回退：不传 `--open-on-start` 则不自动初始张开；`--return-to-start-opening` 恢复松开到初始开度。`--commissioning-limits` 仍保留初始开度安全上限，因此不是全开模式，日志明确记录。

机器人音量原先已是100。播报现在只在播放时处理PCM，以24%满幅RMS为目标、最多8倍预增益，通过软限幅把峰值控制在92%以内；源PCM缓存、Kokoro男声、采样率和声音模型不变。现场测试句RMS由1741提升到6888（约+11.95dB，相比第一版增强再提升约+6.31dB）。用户已确认“明显更响，清楚”。这是音频信号电平变化，不是实测声压级。

验收：93项控制台测试、29项采集与语音测试通过；仅loopback且到机器人无路由的独立netns内，自动张开、左右独立、全开端点误差小于0.01rad、断流停发和不自动恢复通过。真机夹爪开合、机械最大开度和摔后硬件状态未执行验收。
