## 两个结束按钮

“结束并保存”只结束当前episode。新增“结束本批次·下次从第1段开始”：若正在录制，先保存本段，再归档旧计数；下一段从1开始，batch_id与完整session/episode路径保证可区分。旧原始片段不重编号、不覆盖。

批次结束不停止身体控制或夹爪控制，不代替急停。单独离线重置须取得recorder.lock；外部录制器运行时拒绝重置。运行中的工作站通过已有命令文件让录制器执行结束/保存/切批次，不直接改其计数文件。
